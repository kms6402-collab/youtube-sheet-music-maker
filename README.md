# 유튜브 악보 메이커 v2.3.0

유튜브 강의/연주 영상에 나오는 악보 화면을 자동으로 캡처해 하나의 PDF로 모아주는 Windows 데스크톱 앱입니다.

## 흐름

1. 유튜브 주소 입력(또는 **검색**으로 제목/작성자 찾기) → **영상 로드** — 다운로드 없이 스트림 주소만 확인
2. 미리보기에서 **드래그**하거나 좌측 크롭 X/Y/폭/높이 값으로 악보 영역 지정 (또는 **자동 인식** 버튼)
3. **자동 감지 시작** → 영상을 재생하며(다운로드 없이 스트리밍) 설정한 간격으로 프레임을 훑어 유사 프레임을 중복으로 표시
4. 가운데 캡처 목록에서 필터(전체/포함만/제외만)로 원하는 항목만 보며 삭제·순서 변경·포함 여부 조정,
   **편집** 버튼으로 사각형/붓 지우개로 원치 않는 부분 지우기, 필요하면 **캡처 추가**로 수동 캡처
5. 우측 PDF 출력 설정(용지, 5단 고정 그리드, 여백, DPI, 표지, 페이지 번호, 저장 경로) 후 **PDF로 내보내기**
6. **파일 > 프로젝트 저장**으로 `.scap` 파일에 진행 상황을 저장해두고 나중에 이어서 작업 가능

## 실행 전 준비물

- **yt-dlp.exe**: 첫 실행 시 상단에 노란 배너로 안내되며, **"yt-dlp 다운로드"** 버튼을 누르면
  공식 GitHub 릴리스에서 내려받아 `tools/yt-dlp.exe`에 저장합니다. (자동으로 실행되지 않고,
  반드시 버튼을 눌러야 다운로드가 시작됩니다.) 이미 PATH에 yt-dlp가 설치되어 있다면 그걸 사용합니다.
- **ffmpeg는 필수 아님**: 병합이 필요 없는 영상 전용 스트림을 우선 받도록 되어 있습니다.

## 빌드 / 실행

.NET 10 SDK가 필요합니다. (`net10.0-windows` 타깃 — 다른 PC에서 net8.0 런타임만 있다면
`ScoreCap.csproj`의 `TargetFramework`를 `net8.0-windows`로 바꾸고 해당 SDK로 빌드하세요.)

```powershell
# 개발 중 실행
dotnet run -c Debug

# 배포용 단일 실행 파일 (다른 PC에 .NET 설치 없이 실행 가능, ~220MB)
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

`publish/유튜브 악보 메이커 v2.3.0.exe` 하나만 복사해서 배포하면 됩니다. 미리 빌드된 실행 파일은
[Releases](../../releases) 페이지에서 받을 수 있습니다.

## 구조

- `Views/MainWindow.xaml(.cs)` – 3분할 UI (미리보기·크롭 / 캡처 결과 / PDF 출력), 크롭 드래그 처리
- `Views/SearchWindow.xaml(.cs)` – 유튜브 검색(제목/작성자, 일반/정규식/와일드카드) + 썸네일
- `Views/ImageEditorWindow.xaml(.cs)` – 캡처 후 보정 편집기 (사각형/붓 지우개, 실행 취소)
- `ViewModels/MainViewModel.cs` – 전체 화면 상태와 커맨드 (MVVM, CommunityToolkit.Mvvm)
- `Services/YtDlp` – yt-dlp.exe 탐색·다운로드, 스트림 주소 조회, 검색
- `Services/Capture` – OpenCvSharp 기반 프레임 스캔(스트리밍 순차 재생), 유사도 비교(중복 감지),
  크롭/기울기 보정/대비 향상/업스케일링, 악보 영역 자동 인식(오선 수평선 밀도 휴리스틱)
- `Services/Pdf` – PdfSharp으로 PDF 생성 (용지/여백/5단 그리드/표지/페이지 번호/DPI 반영, 한글 폰트)
- `Services/Project` – `.scap` 프로젝트 저장/불러오기 (JSON)

## 알아두면 좋은 점

- "악보 자동 인식"은 AI 인식이 아니라 오선의 긴 수평선 패턴을 찾는 이미지 처리 휴리스틱입니다. 화면 구성이
  특이한 영상에서는 결과가 부정확할 수 있어 수동 크롭 드래그로 보정하는 걸 권장합니다.
- 유사도 기반 중복 판정은 픽셀 차이(MAD)를 사용합니다. 너무 자주 중복으로 잡히면 "중복 판정 유사도" 슬라이더를
  올리고(더 엄격하게), 너무 안 잡히면 내리세요.
- 캡처 속도는 스트림 해상도에 좌우됩니다(네트워크 대역폭 병목). 480p가 가장 빠르고, 업스케일링 옵션으로
  최종 출력 화질을 보완합니다.
- 저작권이 있는 영상을 개인 학습·연습 목적 외로 재배포하지 않도록 주의하세요.
